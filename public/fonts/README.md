# Bundled fonts

- **Sahel** is used for Persian headings. Source: https://github.com/rastikerdar/sahel-font. Licensed under the SIL Open Font License 1.1; see `sahel/LICENSE`.
- **Vazirmatn** is used for Persian body text and controls. Vazirmatn is the maintained continuation of the Vazir typeface. Source: https://github.com/rastikerdar/vazirmatn. Licensed under the SIL Open Font License 1.1; see `vazirmatn/OFL.txt`.

The font files are self-hosted with the site so Persian pages do not depend on a third-party font CDN.
